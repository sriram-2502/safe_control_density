Example family

Single Integrator

A planar point robot with directly commanded velocity. These examples compare density feedback, one-step density filtering, and CLF-CBF filtering.

Model

$$ p_{k+1}=p_k+\Delta t\,u_k, \qquad u_k=[u_x,u_y]^T $$

Density Function

For the single-integrator model, the density is defined directly over planar position. The same obstacle bump construction is used, but there is no heading term.

Position Density

The goal term grows as the point robot approaches \(p_g\).

$$ \rho(p)=\frac{\Phi(p)}{\|p-p_g\|^{2\alpha}}, \qquad \Phi(p)=\prod_i b_i(p) $$

Circle Example

For a circular obstacle centered at \(c\), use \(d(p)=\|p-c\|_2\).

$$ m(p)=\frac{\|p-c\|_2^2-r_1^2}{r_2^2-r_1^2} $$

Controller Formulations

Density Feedback

The direct controller follows the density gradient with optional saturation.

$$ u(p)=k_\rho\nabla\rho(p) $$

Density Filter

The one-step filter modifies a nominal velocity only when needed for the density condition.

$$ \begin{aligned} \min_{u,s}\;&\frac{1}{2}\|u-u_{\mathrm{nom}}\|_W^2+\frac{1}{2}w_s\|s\|^2\\ \mathrm{s.t.}\;& \rho(p_{k+1})-\rho(p_k)+s\ge 0 \end{aligned} $$

CLF-CBF Filter

The CBF baseline uses a hard geometric safety condition for the inflated obstacle.

$$ h(p_{k+1})\ge (1-\gamma)h(p_k), \qquad h(p)=\|p-c\|^2-R^2 $$

Why No Density MPC Here?

The single-integrator dynamics directly control planar velocity, so the one-step filter already has direct authority over the next position.

Static Obstacle

Direct feedback follows the density gradient, while the filter minimally modifies a nominal command to satisfy the density condition.
