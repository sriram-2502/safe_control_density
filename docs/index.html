Overview

These examples build a smooth density field that is high near the goal and suppressed near obstacles. Controllers then either follow the density gradient directly or enforce a one-step or finite-horizon density transport condition.

$$ \rho(z)=\frac{\Phi(p)}{V(z)^\alpha}, \qquad \Phi(p)=\prod_i b_i(p) $$

Representative Rollouts

Unicycle Density MPC

Short-horizon density MPC steers a nonholonomic robot around a static obstacle.

Local Sensing

The controller only activates obstacles that are sensed or held in short-term memory.

Racing Density MPC

Density MPC-CDF tracks a circuit while avoiding moving obstacle cars.

Density Safety Filter

The one-step density filter minimally modifies a nominal command \(u_{\mathrm{nom}}\) so the next state satisfies a discrete density condition.

$$ \begin{aligned} \min_{u,s}\quad &\frac{1}{2}\|u-u_{\mathrm{nom}}\|_W^2+\frac{1}{2}w_s\|s\|^2 \\ \mathrm{s.t.}\quad &\rho(z_{k+1})-\rho(z_k)+\Delta t\,\mathrm{div}(F_d)\rho(z_k)+s\ge 0 \end{aligned} $$

Controller Comparisons

Density Feedback vs Filter vs MPC

Direct feedback follows the density field, the filter solves a one-step safety problem, and MPC reasons over a finite horizon.

Density and CBF Safety Filters

One-step CLF-CBF stays safe but can park at the obstacle; MPC-style controllers recover steering through the prediction horizon.

Reproduce

Install the package in editable mode, then run any example script from the repository root.

python -m pip install -e .
python examples/unicycle/static_single_obstacle/density_mpc.py --save-mp4 --horizon 7 --no-plot
python examples/unicycle/static_single_obstacle/compare_safety_filters.py --no-show
